## 運用上の教訓
- 共有チェックアウトでデプロイAgentが作業中に指揮AIが docs を編集すると、Agent 側で `git stash` 退避が必要になった（今回2回）。**デプロイAgent稼働中は docs も編集しない**（メモを scratchpad に書いておき、完了後に台帳へ）
- 調査Agent（読み取り専用・本番DBコピー）→ R番号採番→修正Agent、の流れは速い。板２（データ正常・表示バグ）とガント極小バー（仕様と実装の取り違え）はどちらも「見た目の症状」と「原因」が別物だった
- 「テスト名は仕様、アサーションは実装」の取り違えテストが存在した（R-145）。テストを直すときは「実装に合わせる」のではなく「仕様に合わせる」旨をコメントに残す運用を Agent に指示した
- 本番検証で「はみ出し」など日付依存の状態は翌日に消える。検証できなかった項目はユニットテストで担保した旨を台帳に明記する
