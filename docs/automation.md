# 運用自動化と索引

同じ転記・確認・検索を繰り返す、または記録漏れが起きやすい場合、指揮AIは小さな自動化を提案または作成してよい。

## 境界

- Markdownの要望・仕様・台帳は正本。SQLite、HTML、ダッシュボードは原則として再生成できる索引・表示にする
- 自動化は可逆で、失敗しても手作業へ戻れるようにする
- 外部サービス、課金、認証情報、権限、公開範囲を変える場合は発注者に確認する
- `.sddd/` とCodeGraphの `.codegraph/` は再生成可能なローカルデータとして既定でGit管理外にする。共有する設定や出力が必要な時だけ、対象・理由・更新者をチームで決める

## 候補

- 要望ID、spec、タスク、Issue、PRのリンク検査
- 引継書・コンテキストパックの下書き
- MarkdownからSQLite索引・HTMLダッシュボードを生成
- CodeGraphなどでコード影響範囲の候補を検索し、実際に読むファイルと検証項目をタスクへ記録

自動化を作る前に、目的、入力、出力、正本、失敗時の戻し方を短く記録する。

## CodeGraph連携（推奨）

[CodeGraph](https://github.com/colbymchenry/codegraph) は、コードの依存関係と変更影響を調べるローカルのコード索引である。複数モジュールをまたぐ変更、既存コードの変更、並列実装、レビューでは優先して使う。

1. 要望ID、仕様、受け入れ条件を読む
2. CodeGraphで入口、呼び出し関係、影響候補を調べる
3. 実際に変更・確認するファイル、リスク、テスト項目をタスクまたはPRへ記録する
4. 実装後は仕様・受け入れ条件・テスト結果で完了を確認する

CodeGraphの結果は影響調査の補助であり、仕様の正本でも完了根拠でもない。

## Youkan固有: 進捗ダッシュボード連携

### Phase 4 開始時の必須手順

**Agent起動前に以下を必ず実行する。省略禁止。**

1. **複数の要望がある場合は、すべての仕様確定を終えてから**タスクに分解する
2. タスクを分解し、プロジェクトルートに `task.md` を作成（チェックボックス付き）
3. ユーザーに「別のターミナルで以下のコマンドを実行すると進捗を確認できます」と**絶対パス付き**で案内
   - 例: `sdd-dashboard C:\Fujiruki\Projects\Youkan\task.md`
4. **案内後、ユーザーの確認を待たずにAgentを起動する**

### `task.md` の更新タイミング

- Phase 4 開始時: タスク分解結果を `task.md` に記載
- Phase 4 中: **Agentがサブタスク完了ごとにチェックボックスを `[x]` に更新する**
- Phase 5（レビュー完了）時: ステータスを「完了」に更新

### Agentへの指示に含めること

Agentに実装を依頼する際、以下を必ずプロンプトに含める:
- `task.md` のパスと、完了したサブタスクのチェックボックスを `[x]` に更新する指示

## Youkan固有: Agent完了の判定強化（chrome-devtools MCP必須）

Agent のテスト緑＋デプロイ成功だけでは「完了」としない。以下を必須とする:

1. **`chrome-devtools MCP` で実機操作**
   - 主要ツール: `navigate_page`, `take_snapshot`, `click`, `take_screenshot`, `evaluate_script`
   - 修正対象機能を実画面で再現し、ON/OFF や Before/After のスクリーンショット 2 枚以上を取得
2. **ログイン状態の準備**
   - 本番 (`http://door-fujita.com/contents/Youkan/`) でのログインが必要な場合、テスト用アカウントの認証情報を Agent prompt に含めるか、`localStorage` への JWT 直接注入の手順を指示する
   - これらを Agent prompt の「実機検証」セクションに最初から書く（後付け禁止）
3. **指揮 AI による報告フォーマット**
   - スクリーンショット添付で発注者へ報告
   - 「実機で動作確認しました」ではなく「スクリーンショット A: 修正前、スクリーンショット B: 修正後」を明示

参考: chrome-devtools MCP は `npx chrome-devtools-mcp` で稼働中。Windows では `cmd /c npx` 経由起動推奨。
